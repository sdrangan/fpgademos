# GitHub Repository

All the class material is in the [GitHub repository](https://github.com/sdrangan/hwdesign).

For those not familiar with GitHub, you can follow the guide on the [GitHub Docs page](https://docs.github.com/en/get-started/start-your-journey/hello-world) for using github.  This directory will provide some general commands useful for the GitHub repo of this class.

Students should read the first two pages in order:

1. [Cloning the Repository](./repo.md) — get the course material onto your machine.
2. [Installing the Python packages](./package.md) — set up a virtual environment
   and install `waveflow` and `hwdesign`.

The third page, [Developer Setup](./developer.md), is only for instructors and
course assistants who are modifying course material or the `waveflow` package
itself. It is not needed to take the course.
