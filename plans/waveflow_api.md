- **No top-level re-exports.** `import waveflow` exposes only the subpackages
  (`build`, `calib`, `hw`, `mcp`, `named`, `scripts`, `simulation`, `toolchain`,
  `utils`). So imports are deep, e.g. `from waveflow.hw.dataschema import DataArray`,
  `from waveflow.utils import fixputils`, not `from waveflow import DataArray`.
